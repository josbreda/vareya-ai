## WAARNEMINGS-BEPERKINGEN

- Deze baseline gebruikt neutrale web search — geen Nederland-geolokte zoekresultaten.
- Google Maps local pack data is niet beschikbaar via deze methode.
- **Vereist:** Search Console toegang + handmatige Breda-geolokte checks + lokale rank-grid tool voor betrouwbare vervolgmetingen.
